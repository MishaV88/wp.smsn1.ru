## Что это за проект

Плагин заменяет стандартную форму входа на вход по номеру телефона:

1. пользователь вводит `+7XXXXXXXXXX`;
2. получает 5-значный код из СМС (живёт 90 секунд, 5 попыток);
3. после проверки кода ставится auth-cookie WordPress (`wp_set_auth_cookie` + `wp_login`).

Дополнительно: вход через **VK ID** (OAuth 2.1 + PKCE), **Telegram** (Login Widget),
режим **2FA** (пароль + код), подтверждение номера на checkout WooCommerce.

СМС отправляются через сторонний сервис smsn1.ru (`direct.docs-group.ru`), API — только HTTPS.


## Инварианты: не ломать

1. **Совместимость PHP 5.6+.** Запрещены `??`, стрелочные функции, типизированные свойства,
   `str_contains`, `array_key_first`. Тип возврата — только в PHPDoc.
2. **Префикс `wp_smsn1_ru_`** у всех глобальных функций и опций. Плагин без пространств имён.
3. **Версия в трёх местах**: `Version:` в заголовке, `Stable tag:` в `readme.txt`,
   верхняя запись в `CHANGELOG.md`. `bin/check-version.php` сверяет, release-workflow
   не даст выпустить тег с расхождением.
4. **Номер телефона — ключ аккаунта** (`user_meta.billing_phone`, формат `+7XXXXXXXXXX`).
   Дубликаты недопустимы: перед записью проверяй `wp_smsn1_ru_get_user_by_phone()`.
5. **Автомержа аккаунтов нет.** Совпадение e-mail или телефона не повод логинить в чужой
   аккаунт: только явная привязка из авторизованной сессии.
6. **Экранирование и санитизация** на всех выводах/вводах; nonce во всех AJAX.
7. **Секреты не в коде**: логин, API-ключ, client_id, токен бота — только `get_option()`.
8. **HTTPS только.** HTTP-фолбэк для API возможен лишь через константу
   `WP_SMSN1_RU_ALLOW_HTTP_FALLBACK` и по умолчанию выключен.

## Ловушки, на которых уже спотыкались

| Место | Подводный камень |
|---|---|
| VK redirect_uri | VK **не принимает query-параметры** в redirect URL. Поэтому чистый путь `/wp-smsn1-ru-oauth/` через rewrite, а не `admin-post.php?action=…` |
| VK токен | `device_id` возвращает сам VK в callback, его нельзя генерировать самим; `state` обязателен и при обмене кода |
| VK scope | `email phone` можно просить только после одобрения доступов, иначе вход падает с `invalid_scope` |
| Telegram | Виджет **не передаёт телефон и e-mail**, только `id`, имя, `auth_date` и `hash`; вход всегда создаёт аккаунт без телефона |
| Telegram домен | Обязателен `/setdomain` в @BotFather, иначе `Bot domain invalid` |
| Telegram в РФ | `telegram.org`, `t.me`, `api.telegram.org` у части провайдеров блокируются — есть плашка-подсказка |
| Баланс | При балансе < 10 ₽ или сбое API форма СМС заменяется экраном с входом по паролю и соцсетями |
| 2FA | Работает только на форме плагина; `wp-login.php` пускает по одному паролю, если не включён редирект |
| Шаблоны | Копия шаблона в теме перекрывает плагин: правки в `templates/` могут не примениться |
| Кэш | CSS/JS подключаются с `?ver=<версия>` — после правок поднимай версию, иначе браузер отдаст старое |

## Безопасность (что уже сделано)

- OTP: 5 цифр, 90 секунд, 5 попыток, `hash_equals`, транзиент по `md5(phone)`.
- Лимиты отправки: 60 секунд пауза, 3 кода на номер и 10 на IP за 20 минут (фильтры).
- VK: PKCE S256, `state` на сервере (10 минут, одноразовый), `wp_validate_redirect`.
- Telegram: `HMAC-SHA256` с ключом `SHA256(bot_token)`, свежесть `auth_date` ≤ 15 минут.
- API smsn1.ru: HTTPS, таймаут 8 секунд, проверка сертификата.
- Привязка провайдера: одноразовый токен (10 минут), принимается только в том аккаунте,
  из которого открыт.
