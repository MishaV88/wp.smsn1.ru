Вход и регистрация по коду из СМС, режим 2FA, вход через VK ID и Telegram, подтверждение номера на checkout WooCommerce.

== Description ==

Плагин заменяет стандартную форму входа на вход по номеру телефона: пользователь вводит
номер, получает одноразовый код из СМС и попадает в свой аккаунт. Пароль не нужен —
аккаунт создаётся автоматически при первом входе.

Дополнительно поддерживаются вход через **VK ID**, **Telegram** и режим **2FA**
(пароль + код из СМС).

= Возможности =

* Вход и регистрация по номеру телефона и коду из СМС.
* Код из 5 цифр, срок действия 90 секунд, не более 5 неверных попыток на код.
* Защита от SMS-бомбинга: пауза 60 секунд, 3 кода на номер и 10 на IP за 20 минут.
* Режим 2FA: на форме появляется поле пароля — нужны и пароль, и код.
* Вход через VK ID (OAuth 2.1 + PKCE) и Telegram (Login Widget).
* Привязка VK и Telegram к существующему аккаунту из личного кабинета.
* Подтверждение номера телефона на классической странице оформления заказа WooCommerce.
* Шорткоды форм и собственные шаблоны в теме.
* Если СМС недоступны (баланс меньше 10 ₽ или сбой сервиса), остаётся вход
  по логину и паролю, а также через VK и Telegram.

= Внешний сервис =

Плагин **не отправляет СМС самостоятельно**. Для отправки используется сервис
„smsn1.ru" (личный кабинет — `direct.docs-group.ru`):

* нужен аккаунт и баланс в сервисе — СМС платные, оплачиваются напрямую сервису;
* при отправке на сервер сервиса передаются: номер телефона, текст сообщения,
  логин и подпись запроса (API-ключ не передаётся);
* запросы идут только по HTTPS;
* сайт и условия: https://wp.smsn1.ru/ , поддержка: https://wp.smsn1.ru/контакты-службы-поддержки/ .

Без настроенного аккаунта плагин не сможет отправить код, но остальные функции
(форма, настройки, вход через VK/Telegram) работают.

= Требования =

* WordPress 5.6+
* PHP 7.4+
* WooCommerce — опционально
* Аккаунт smsn1.ru с одобренным именем отправителя
* Доставка СМС — только на номера Российской Федерации

== Installation ==

1. Установите плагин: «Плагины → Добавить новый → Загрузить плагин» или через поиск по каталогу.
2. Активируйте плагин.
3. Зарегистрируйтесь в сервисе smsn1.ru, скопируйте логин и API-ключ из раздела API.
4. Откройте «WP.SMSn1.RU» в админ-меню, введите логин и ключ, выберите отправителя СМС.
5. Проверьте ссылки и редиректы в настройках плагина.
6. При желании включите VK ID и Telegram в разделе «Способы входа».

После активации создаются страницы «Войти на сайт» (`login-by-wp-smsn1-ru`),
«Регистрация» (`registation-by-wp-smsn1-ru`) и «Политика обработки персональных данных».

== Frequently Asked Questions ==

= Нужен ли платный аккаунт? =

Да. Плагин бесплатный, платите только за СМС в сервисе smsn1.ru. Без аккаунта отправка
кодов работать не будет, но вход через VK ID и Telegram остаётся доступен.

= Почему не приходит код? =

Проверьте баланс, выбранного отправителя и лимиты: не более 3 кодов на номер
и 10 на IP за 20 минут, пауза между отправками — 60 секунд.

= Работает ли с зарубежными номерами? =

Нет. Сервис доставляет СМС только на номера РФ. Для зарубежных пользователей
предусмотрены VK ID и Telegram.

= Почему в России не показывается кнопка Telegram? =

У части провайдеров домены Telegram блокируются, поэтому виджет не загружается —
плагин показывает подсказку и предлагает СМС или VK ID.

= Где хранятся номера телефонов? =

В мета-поле `billing_phone` пользователя WordPress. Автоматического объединения
аккаунтов по e-mail или телефону нет — только явная привязка из профиля.
