# AGENTS.md

Точка входа для ИИ-агентов, которые анализируют или меняют этот репозиторий.

Основной контекст — в [CLAUDE.md](CLAUDE.md): что за проект, карта кода, инварианты,
подводные камни и как прогнать проверки. Он подходит любому агенту, не только Claude.

Коротко:

```bash
php tests/otp-test.php && php tests/telegram-test.php && php bin/check-version.php
bash bin/build.sh
```

Правила: PHP 5.6+, префикс `wp_smsn1_ru_`, версия синхронно в заголовке / `readme.txt` /
`CHANGELOG.md`, никакого автомержа аккаунтов, секреты только в опциях.
