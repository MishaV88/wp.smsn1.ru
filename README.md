# WP.SMSn1.RU — вход по номеру телефона, OTP, 2FA, VK ID и Telegram

[![CI](https://github.com/MishaV88/wp.smsn1.ru/actions/workflows/ci.yml/badge.svg)](https://github.com/MishaV88/wp.smsn1.ru/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/MishaV88/wp.smsn1.ru)](https://github.com/MishaV88/wp.smsn1.ru/releases/latest)
[![License: GPL-2.0+](https://img.shields.io/badge/license-GPL--2.0%2B-blue.svg)](LICENSE)

Плагин WordPress для входа и регистрации **по номеру телефона через одноразовый код из СМС (OTP)**,
с дополнительными способами входа — **VK ID** и **Telegram**, режимом **2FA (пароль + OTP)**,
SMS-уведомлениями и подтверждением номера на оформлении заказа WooCommerce.

Отправка СМС — через сервис [smsn1.ru](https://wp.smsn1.ru/) (личный кабинет: `direct.docs-group.ru`).

> Доставка СМС работает только на номера **Российской Федерации**.

---

## Возможности

**Вход и регистрация**

- Вход по номеру телефона и коду из СМС; регистрация с e-mail или быстрая — без него.
- Код из 5 цифр, живёт 90 секунд, не более 5 неверных попыток на код.
- Защита от SMS-бомбинга: пауза 60 секунд, 3 кода на номер и 10 на IP за 20 минут.
- Режим **2FA**: на форме появляется поле пароля — нужны и пароль, и код.
  Пользователи, созданные в режиме «только OTP», задают пароль при первом входе.

**Дополнительные способы входа**

- **VK ID** — OAuth 2.1 + PKCE, отдельный callback `/wp-smsn1-ru-oauth/`, привязка к аккаунту из личного кабинета.
- **Telegram** — Login Widget с проверкой подписи `HMAC-SHA256`, привязка по одноразовому токену.
- Кнопки соцвхода показываются под формой СМС, отделены разделителем «или».

**WooCommerce**

- Подтверждение номера телефона на классической странице оформления заказа.
- Проверка занятости номера при создании аккаунта на checkout.
- Блок «Способы входа» в личном кабинете (`Мой аккаунт`).

**Прочее**

- Шорткоды форм, шаблоны переопределяются в теме.
- Единые уведомления в формах (success / warning / error) с `aria-live`.
- HTTPS-клиент API, таймауты, понятные ошибки, лимиты и логирование последней ошибки API.
- Если СМС недоступны (баланс < 10 ₽ или сбой сервиса) — вместо заглушки остаются
  вход по логину/паролю и соцвход.
- Публичные функции и хуки для отправки СМС из своего кода.

## Установка

1. Скачайте `wp-smsn1-ru.zip` из [Releases](https://github.com/MishaV88/wp.smsn1.ru/releases/latest)
   (не «Code → Download ZIP»: там исходники репозитория, а не готовый плагин).
2. «Плагины → Добавить новый → Загрузить плагин» → выберите архив → «Установить» → «Активировать».
3. Зарегистрируйтесь в сервисе smsn1.ru, скопируйте **логин** и **API-ключ** из раздела API.
4. «WP.SMSn1.RU» в админ-меню → введите логин и ключ → выберите отправителя СМС.
5. Проверьте ссылки и редиректы в настройках.

После активации создаются страницы:

| Страница | Адрес | Шорткод |
|---|---|---|
| Войти на сайт | `/login-by-wp-smsn1-ru/` | `[wp_smsn1_ru_login_form]` |
| Регистрация | `/registation-by-wp-smsn1-ru/` | `[wp_smsn1_ru_register_form]` |
| Политика обработки ПД | `/privacy-policy/` | — |

## Настройка

### 1. СМС-сервис

| Поле | Что указать |
|---|---|
| Логин | логин из личного кабинета smsn1.ru |
| API-ключ | ключ из раздела API |
| Отправитель SMS | одобренное имя отправителя |

Баланс показывается на странице настроек и обновляется раз в 2 минуты. При балансе ниже 10 ₽
формы возвращают экран с альтернативными способами входа.

### 2. Режим входа

Раздел «Режим входа»:

- **Только OTP** (по умолчанию) — номер + код из СМС;
- **Пароль + OTP** — на форме добавляется пароль (2FA). Пароль проверяется до расхода кода,
  действует лимит 5 неверных попыток за 15 минут.

### 3. VK ID

1. Создайте приложение на <https://dev.vk.com/> — платформа **«Веб»**.
2. В настройках приложения добавьте доверенный Redirect URL:

   ```
   https://ваш-домен.ru/wp-smsn1-ru-oauth/
   ```

   (без query-параметров, с `https://` и слэшем на конце; VK сравнивает строку целиком).
3. В настройках плагина, раздел «Способы входа»:
   - включите VK ID;
   - укажите **ID приложения** (`client_id`);
   - защищённый ключ обычно не нужен (используется PKCE);
   - **scope** оставьте пустым, пока VK не одобрил доступы. После одобрения e-mail/телефона
     впишите `email phone` — иначе вход упадёт с `invalid_scope`.

Привязка VK к существующему аккаунту — в личном кабинете («Способы входа» → «Привязать»)
или в профиле админки. После привязки телефон из VK подставляется в аккаунт, если там пусто.

### 4. Telegram

1. [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен.
2. Там же `/setdomain` → выберите бота → отправьте домен сайта **без** `https://` и слэша,
   например `wp.smsn1.ru`. Без этого виджет вернёт `Bot domain invalid`.
3. В настройках плагина укажите username бота и токен, включите Telegram.

Telegram не передаёт телефон и e-mail, поэтому вход через него создаёт аккаунт без них;
привязать Telegram к существующему аккаунту можно из личного кабинета (виджет с одноразовым токеном).

> В России домены `telegram.org`, `t.me` и `api.telegram.org` у части провайдеров недоступны.
> В этом случае виджет не загружается — плагин показывает подсказку и предлагает СМС или VK.

### 5. Ссылки и сессии

- Ссылки на страницы входа/регистрации, редиректы после входа и выхода.
- Редирект со стандартной `wp-login.php` и со страницы `/my-account/` WooCommerce.
- Время жизни сессии в часах («Запомнить меня» включено по умолчанию).

## Шорткоды

| Шорткод | Назначение |
|---|---|
| `[wp_smsn1_ru_login_form]` | форма входа |
| `[wp_smsn1_ru_register_form]` | форма регистрации |
| `[wp_smsn1_ru_phone_verification]` | поле телефона + кода для checkout |
| `[wp_smsn1_ru_login_methods]` | блок привязки VK/Telegram для авторизованного пользователя |

Шаблоны форм лежат в `templates/` и переопределяются в теме:

```
wp-content/themes/<тема>/wp-smsn1-ru/login-form.php
wp-content/themes/<тема>/wp-smsn1-ru/register-form.php
...
```

## Публичный API

```php
// Отправить произвольное СМС
$result = wp_smsn1_ru_do_send_function('+79991234567', 'Текст сообщения');
// true | строка с ошибкой

// Баланс и отправители
$balance = wp_smsn1_ru_get_balance();   // float | 'Проблема с соединением'
$senders = wp_smsn1_ru_get_senders();   // массив одобренных отправителей
```

Хуки: `wp_smsn1_ru_send_function`, `wp_smsn1_ru_get_balance`, `wp_smsn1_ru_get_senders`,
`wp_smsn1_ru_auth_providers` (добавление своего провайдера входа),
`wp_smsn1_ru_send_cooldown`, `wp_smsn1_ru_send_limit_phone`, `wp_smsn1_ru_send_limit_ip`,
`wp_smsn1_ru_send_window`, `wp_smsn1_ru_otp_max_attempts`, `wp_smsn1_ru_telegram_max_age`.

## Безопасность

| Механизм | Значение |
|---|---|
| Код подтверждения | 5 цифр, 90 секунд, 5 попыток |
| Отправка СМС | 60 секунд пауза, 3 на номер и 10 на IP за 20 минут |
| Пароль (2FA) | 5 неверных попыток за 15 минут |
| VK ID | OAuth 2.1 + PKCE S256, `state` на сервере (10 минут, одноразовый) |
| Telegram | `HMAC-SHA256(SHA256(bot_token))`, `hash_equals`, `auth_date` ≤ 15 минут |
| API smsn1.ru | только HTTPS, таймаут 8 секунд, проверка сертификата |
| Аккаунты | автоматического объединения по e-mail/телефону нет — только явная привязка |

Подробнее — [SECURITY.md](SECURITY.md). Об уязвимостях пишите в поддержку, не в публичный issue.

## Разработка

```bash
git clone https://github.com/MishaV88/wp.smsn1.ru.git
cd wp.smsn1.ru

bash bin/build.sh            # сборка архива (Linux/macOS)
pwsh -File bin/build.ps1     # сборка архива (Windows)

php tests/otp-test.php       # тесты кодов и лимитов
php tests/telegram-test.php  # проверка подписи Telegram
php bin/check-version.php    # сверка версий: заголовок / readme / CHANGELOG
```

Архив собирается в `dist/wp-smsn1-ru.zip` и в git не попадает. Релиз публикуется тегом
`v<версия>`, совпадающим с `Version:` в заголовке плагина:

```bash
git tag v1.8.0
git push origin v1.8.0
```

GitHub Actions проверит синтаксис на PHP 7.4–8.3, прогонит тесты, соберёт архив и приложит
его к релизу.

## Устранение неполадок

| Симптом | Причина и что делать |
|---|---|
| «Вход по коду временно недоступен» | баланс меньше 10 ₽ или нет связи с сервисом — пополните баланс; вход по паролю и соцсети работают |
| «Ошибка при отправке СМС: #13» | номер в стоп-листе сервиса |
| «Не выбран отправитель SMS» | выберите отправителя в настройках (список грузится раз в 4 минуты) |
| VK: `invalid_scope` | в scope указаны доступы, которые VK ещё не одобрил — оставьте поле пустым |
| VK: `redirect_uri mismatch` | адрес в кабинете VK не совпадает с `/wp-smsn1-ru-oauth/` символ в символ |
| Telegram: `Bot domain invalid` | не выполнен `/setdomain` в @BotFather |
| Кнопки Telegram нет | сеть блокирует `telegram.org` — показывается подсказка, используйте СМС или VK |
| Не приходит код | проверьте баланс, отправителя и лимиты (3 кода на номер за 20 минут) |
